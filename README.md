
# SpendWise Dashboard

## Project Description

SpendWise is a responsive personal finance dashboard built using HTML5 and CSS3.

The project demonstrates modern CSS layout techniques, including CSS Grid and Flexbox, to create a clean and organized financial dashboard.

## Features

- Sidebar navigation menu.
- Dashboard header with user profile.
- Financial summary cards.
- Six expense category cards:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Savings
  - Utilities
- Responsive layout for mobile screens.
- CSS hover and keyboard focus animations.
- Light and dark themes using CSS custom properties.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Media Queries

## Layout Techniques

### CSS Grid
CSS Grid is used to create the overall dashboard layout, financial summary and expense category cards.

### Flexbox
Flexbox is used to arrange the sidebar navigation, header elements, profile section and individual category card content.

### Responsive Design
A media query adapts the dashboard into a single-column layout on screens below 768px.

### Dark Theme
The application supports the user's operating system color preference through the prefers-color-scheme media feature.

### Micro-interactions
Category cards include smooth hover and keyboard focus animations lasting 200 milliseconds.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Resize the browser to test the responsive layout.
